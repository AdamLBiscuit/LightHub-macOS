# LightHub pour macOS

Dépôt public réservé aux téléchargements et notes de version du canal GitHub Mac. Le code Windows, iOS, iPadOS et macOS est regroupé dans le dépôt privé **LightHub** ; l’ancien dépôt privé `LightHub-macOS-Code` est archivé.

[Préversions Mac](https://github.com/AdamLBiscuit/LightHub-macOS/releases) · [Site officiel](https://getlighthub.com/) · [Assistance](https://getlighthub.com/assistance.html)

Mac Apple Silicon · macOS 14 minimum · Français / English

## Canaux de distribution

- **GitHub** : téléchargements historiques et préversions. Ce dépôt reste actif pour les vérifications de mises à jour des versions déjà installées.
- **App Store / TestFlight** : macOS rejoint la même fiche **LightHub** que l’iPhone et l’iPad. La version 0.12.2 (5) a été soumise à Apple ; elle n’est pas encore approuvée au 3 novembre 2026. La version App Store utilise le mécanisme de mise à jour Apple.

Les anciennes préversions GitHub sont signées Apple Development et **non notarisées**. Cette limitation concerne ces fichiers historiques ; consulter leurs notes avant installation. Aucun nouveau DMG n’est publié par cette réorganisation.

Les installateurs restent dans les Releases. Les notes, sommes de contrôle et licences doivent être conservées avec chaque version.

## English

Public downloads and release notes for the GitHub Mac channel. Private source code for Windows, iPhone, iPad and Mac is maintained in one LightHub repository. Existing GitHub releases remain available for update checks. The unified Apple app is awaiting App Review; historical GitHub previews remain development-signed and **not notarized**.
