# LightHub pour Mac — 0.11.0 Beta 2

Version 0.11.0, build 3 · Apple Silicon · macOS 14 minimum.

## Nouveautés

- Recherche automatique quotidienne des mises à jour depuis les releases GitHub publiques.
- Commande « Rechercher les mises à jour… » dans le menu LightHub.
- Réglages pour désactiver la recherche automatique ou exclure les préversions.
- Présentation de la nouvelle version avec ses notes et un bouton de téléchargement.
- Les versions anciennes, brouillons et releases sans installateur compatible sont exclus.

**La détection est automatique ; l’installation reste manuelle via le DMG.** Téléchargez le fichier, quittez LightHub et remplacez l’application dans Applications. Vos catalogues sont conservés. La Beta 1 doit être mise à jour manuellement pour obtenir cette fonction.

Compilation Release, signature et tests ciblés de sélection des versions vérifiés. Aucun test interactif lancé automatiquement.

## Installation

Ouvrir le DMG et glisser LightHub dans Applications.

**Signature Apple Development, non notarisée.** macOS peut bloquer l’ouverture ; l’installation sur d’autres Mac n’est pas garantie. Ce n’est pas une distribution Developer ID ou Mac App Store. [Aide Apple](https://support.apple.com/fr-fr/102445).

## English

Adds daily automatic GitHub release checks, a Check for Updates menu command, an optional prerelease channel and a download button with release notes. Older releases, drafts and incompatible assets are excluded.

**Detection is automatic; installation is manual using the DMG.** Quit LightHub and replace it in Applications. Catalogues are preserved. Beta 1 users must install this build manually to obtain update checks.

Apple Silicon, macOS 14+. Development-signed, **not notarized**; Gatekeeper may block opening and installation on other Macs is not guaranteed.
