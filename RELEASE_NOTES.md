# LightHub pour Mac — 0.11.0 Beta 1

Première préversion macOS, version 0.11.0 (build 2).

- Mac Apple Silicon, macOS 14 ou ultérieur.
- Interface Mac Catalyst, fenêtre librement redimensionnable, menus et raccourcis clavier.
- Développement non destructif, catalogues, presets, masques, MobileSAM et PMRID.
- Quatre photos de test Windows incluses, accessibles depuis l’accueil, dont un original de 60 Mpx.
- Français et anglais ; bibliothèque Mac indépendante de celles sur iOS et Windows.

## Installation et limites

Ouvrir le DMG et glisser LightHub dans Applications.

**Préversion de test signée Apple Development, non notarisée.** Ce n’est pas encore une distribution Developer ID ou Mac App Store. macOS peut bloquer son ouverture et cette signature ne garantit pas l’installation sur tous les Mac. [Informations Apple sur l’ouverture des apps](https://support.apple.com/fr-fr/102445). Ne désactivez pas globalement les protections de macOS.

Apple Silicon uniquement. Pas de synchronisation de catalogue entre plateformes. PMRID : RAW Bayer jusqu’à 25 Mpx, force limitée à 70 %. Les quatre JPEG de démonstration ont été vérifiés par un test de décodage et de rendu ; les essais interactifs de cette compilation restent à effectuer.

## English

First Mac preview: macOS 14+, Apple Silicon, Mac Catalyst, resizable window, keyboard shortcuts, catalogues, presets, creative masks and four bundled Windows sample photos.

**Development-signed, not notarized.** Gatekeeper may block this test build; installation on other Macs is not guaranteed. This is not a Developer ID or Mac App Store distribution. Local catalogues are independent of Windows/iOS. Interactive validation of this build remains pending.
